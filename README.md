# Campus-Safe-Navigation-System

校园安全导航系统项目仓库。

本仓库用于组织校园安全导航系统的前端、后端、地理信息处理、数据管理与文档资料，便于团队协作开发、代码审核和成果沉淀。

## 项目目标

本项目面向校园场景，探索结合地图导航、空间分析与智能能力的安全出行支持系统。系统后续可围绕以下方向逐步建设：

- 校园安全路线规划
- 风险区域识别与避让
- 地图可视化与路径展示
- 调研数据整理与分析
- 基于大模型的问答、解释与辅助决策

## 仓库结构

```text
Campus-Safe-Navigation-System/
├─ backend/    后端服务、接口、业务逻辑
├─ frontend/   前端页面、交互、地图展示
├─ gis/        GIS 数据处理、空间分析、路径规划
├─ llm/        大模型相关能力与实验代码
├─ data/       原始数据、清洗数据、数据说明
├─ survey/     问卷、访谈、调研结果
├─ docs/       项目文档、设计说明、会议记录
├─ outputs/    导出结果、分析产物、可交付内容
└─ README.md   仓库首页说明
```

## 目录说明

### `backend`

用于存放后端服务代码，例如：

- API 接口
- 用户与权限逻辑
- 数据库访问
- 风险评估与路线服务

### `frontend`

用于存放前端应用代码，例如：

- 地图页面
- 路线规划交互
- 风险提示界面
- 可视化组件

### `gis`

用于存放空间数据处理与分析相关内容，例如：

- 校园地图数据
- 路网建模
- 最短路径或安全路径算法
- 空间分析脚本

### `llm`

用于存放与大模型相关的实验和功能，例如：

- 智能问答
- 路线解释生成
- 安全提示文本生成
- 文本分析与总结

### `data`

用于集中管理项目数据，例如：

- 原始采集数据
- 清洗后的结构化数据
- 样例数据集
- 数据字段说明

### `survey`

用于存放调研相关资料，例如：

- 用户问卷
- 访谈提纲
- 调研统计结果
- 用户需求分析

### `docs`

用于沉淀项目过程文档，例如：

- 需求文档
- 系统设计文档
- 开发计划
- 会议纪要
- 使用说明

### `outputs`

用于保存项目输出成果，例如：

- 图表
- 分析报告
- 模型结果
- 演示材料

## 协作建议

为方便仓库管理，建议团队成员采用以下协作方式：

1. 不直接修改 `main` 分支。
2. 每个功能或任务使用独立分支开发。
3. 完成后通过 Pull Request 提交修改。
4. 由仓库负责人审核代码后再合并。

建议 Pull Request 描述中写清楚：

- 修改了什么
- 为什么这样修改
- 影响了哪些目录
- 如何验证功能
