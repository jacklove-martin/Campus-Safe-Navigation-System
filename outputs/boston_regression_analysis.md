# Boston 房价预测模型对比分析

## 实验说明

- 数据集：Boston Housing（OpenML `boston` version 1）
- 样本数：506
- 特征数：13
- 目标变量：`MEDV`（房价中位数）
- 训练测试划分：80% 训练集，20% 测试集，`random_state=42`
- 预处理：中位数填补 + 标准化
- 调参方法：5 折交叉验证，优化指标为 RMSE

> 说明：Boston 数据集因公平性争议已被官方弃用，这里仅用于完成课程/实验中的回归方法比较。

## 结果分析

- 从测试集 RMSE 和 MAE 来看，**Lasso** 的预测效果最好，测试集 RMSE 为 **4.9379**，R² 为 **0.6675**。
- 表现最弱的是 **ElasticNet**，说明在当前划分和参数范围下，它对 Boston 数据集的拟合能力相对更弱。
- **Ridge 回归** 的测试集 R² 为 **0.6671**，整体表现稳定。它通过 L2 正则化抑制系数过大，适合处理多重共线性较明显的数据。
- **Lasso 回归** 的测试集 R² 为 **0.6675**。L1 正则化会压缩部分系数，甚至把一些特征系数压到 0，因此具备一定特征选择能力，但在这个数据集上精度略逊于最优模型。
- **ElasticNet 回归** 结合了 L1 与 L2 正则化，测试集 R² 为 **0.6667**。它通常在“需要稀疏性”与“需要稳定性”之间取得折中。

## 结论

- 如果目标是 **追求当前实验中的最佳预测精度**，优先选择 **Lasso**。
- 如果更关注 **模型稳定性和抗多重共线性能力**，Ridge 回归通常是很稳妥的选择。
- 如果希望 **自动筛选特征、得到更稀疏的模型**，Lasso 或 ElasticNet 更合适。
- 综合这次实验结果，三种方法都能完成房价预测任务，但 **Lasso 在本次实验中综合表现最好**。
